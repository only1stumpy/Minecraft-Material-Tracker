# Статус Minecraft Material Tracker 2.0

Эта страница сверяет код репозитория с [техническим заданием](antville-builder-2.0.md). Здесь отдельно отмечено, что есть в коде и что ещё нужно проверить на реальных данных и устройствах.

## Что подтверждают тесты

CI запускает приложение на поддерживаемых версиях Node.js и PostgreSQL. Набор проверяет парсер схем, арифметику, лимит избытка, права, rate limit, складские резервации, миграции и тестовое восстановление из backup. Это подтверждает работу кода с тестовыми данными; оно не заменяет проверку пользовательских сетей, реальных файлов и отдельной среды восстановления.

Перед отправкой изменений можно запустить локально:

```sh
npm run lint
npm run typecheck
npm test
npx prisma validate
npm run build
git diff --check
```

## Проверки вне кода

1. Сравнить задержку приложения из нескольких сетей игроков и проверить, где находится база данных.
2. Назначить владельца и расписание для зашифрованных копий базы и файлов.
3. Восстановить копию базы и копию хотя бы одного настоящего файла в отдельной среде.
4. Пройти ключевые действия несколькими пользователями; отдельно проверить клавиатурное управление, контраст и телефон.

При создании модератора используйте [короткую инструкцию для администратора](production-moderator.md). Она описывает действия через интерфейс сайта и не требует прямого доступа к базе.
