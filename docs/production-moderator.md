# Как добавить модератора на рабочем сайте

Этот способ подходит, если нужно выдать роль существующему аккаунту или создать новый. Изменения сохраняются через сайт в его рабочую базу данных; подключаться к базе и копировать её ключи не нужно.

## Выдать роль существующему игроку

1. Откройте [рабочий сайт](https://antville.vercel.app) и войдите под аккаунтом с ролью администратора.
2. Перейдите в [панель управления](https://antville.vercel.app/admin).
3. Найдите нужный Minecraft-ник в списке участников.
4. В столбце «Роль» выберите `MODERATOR` (в интерфейсе — «Модератор»).
5. Попросите игрока войти в аккаунт ещё раз. После смены роли старые сессии пользователя отзываются.

Изменение сохраняется в production-базу через сервер Vercel. Действие также записывается в журнале панели.

## Выдать роль существующему PLAYER из терминала Vercel

Этот вариант нужен, если аккаунт уже есть, но у действующего администратора временно нет доступа к `/admin`. Команда запускается из корня проекта и использует `DATABASE_URL`, который уже сохранён в production-переменных Vercel.

Перед запуском проверьте:

- Vercel CLI авторизован: `npx vercel whoami` должен показать вашу учётную запись.
- Папка проекта привязана к нужному production-проекту Vercel. Если привязки нет, выполните `npx vercel link` и внимательно выберите правильный проект.
- Вы находитесь в корне клонированного репозитория, где есть `package.json`.
- Зависимости установлены. В новом клоне один раз выполните `npm ci`, чтобы установить локальные зависимости и сгенерировать Prisma Client.

После проверки выполните команду, заменив `MinecraftNick` на точный Minecraft-ник:

```bash
npx vercel env run -e production -- npm run admin:grant-moderator -- MinecraftNick
```

`vercel env run -e production --` передаёт production-переменные только этому запуску. Команда не скачивает `DATABASE_URL` в файл и не требует копировать секреты в `.env`.

Скрипт повышает только пользователя с текущей ролью `PLAYER`; пароль и другие данные аккаунта он не меняет.

Если аккаунт заблокирован, роль всё равно будет выдана, но блокировка не снимется. Разблокируйте пользователя отдельно через `/admin`.

Результат команды означает следующее:

- `теперь MODERATOR` — роль повышена, старые сессии отозваны, запись добавлена в `AuditLog`.
- `уже MODERATOR` — роль уже выдана, изменений не требуется.
- `не найден` — сначала создайте аккаунт через `/admin` как обычного участника (`PLAYER`), затем повторите команду.
- `уже ADMIN; понижение роли запрещено` — аккаунт администратора скрипт не изменяет.

Эта команда меняет роль в production. Перед запуском ещё раз сверьте Minecraft-ник и выбранный Vercel-проект. Для нового аккаунта используйте основной способ через `/admin` выше.

## Создать новый аккаунт сразу модератором

1. В панели `/admin` откройте форму «Новый участник».
2. Укажите Minecraft-ник и выберите роль «Модератор».
3. Создайте аккаунт и передайте показанный временный пароль лично или через другой закрытый канал. Сайт показывает его только при создании.
4. Попросите нового участника войти и сразу задать постоянный пароль.

## Проверить доступ

- Модератор должен открыть раздел модерации и выполнить доступное ему действие.
- Панель `/admin` доступна только администраторам. Выдача роли модератора не даёт административный доступ.
- Если список участников или смена роли завершились ошибкой, обновите страницу и проверьте журнал ошибок. Не отправляйте пароль и другие секреты в чат.
- Если ни один действующий администратор не может открыть `/admin`, попросите владельца сервиса восстановить административный доступ через его штатный процесс.
