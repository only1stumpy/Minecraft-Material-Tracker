# Запустить свою копию MMT

Эта инструкция поможет скачать Minecraft Material Tracker (MMT) и запустить отдельную копию сайта на своём компьютере. Она подходит человеку, который раньше не запускал веб-проекты.

Рабочий сервис закрытый и с локальной копией не соединён. В локальной базе будут только ваши тестовые аккаунты и постройки. Старые данные в неё не переносятся.

Перед запуском посмотрите [полный список функций MMT](../README.md#what-the-site-can-do) и [статус реализации](v2-implementation-status.md).

## Что понадобится

- **Git** — скачать код проекта: [git-scm.com](https://git-scm.com/downloads).
- **Node.js** — запустить сайт. Нужна версия `22.12+` из ветки `22.x` или `24.11+` из ветки `24.x`: [nodejs.org](https://nodejs.org/en/download/).
- **Docker Desktop** — запустить локальную базу PostgreSQL: [официальная инструкция](https://docs.docker.com/desktop/).

Откройте терминал и проверьте, что программы доступны:

```sh
git --version
node --version
npm --version
docker --version
```

Если установили Docker Desktop, откройте его и оставьте запущенным.

## 1. Скачайте код

В терминале выполните:

```sh
git clone https://github.com/only1stumpy/Minecraft-Material-Tracker.git
cd Minecraft-Material-Tracker
```

Если Git пишет, что репозиторий не найден, проверьте адрес и подключение к интернету. Исходный код можно скачать без аккаунта GitHub; это не открывает доступ к закрытому рабочему сервису.

## 2. Запустите пустую базу для разработки

Скопируйте эту команду в терминал:

```sh
docker run --name mmt-local-db --detach --publish 127.0.0.1:5432:5432 --env POSTGRES_USER=antville --env POSTGRES_DB=antville --env POSTGRES_HOST_AUTH_METHOD=trust --volume mmt-local-db-data:/var/lib/postgresql/data postgres:16
```

Это временная настройка для разработки на своём компьютере. Она слушает только `127.0.0.1` и не должна использоваться на сервере или в общей сети.

Если вы запускали базу раньше и Docker пишет, что контейнер уже существует, включите его:

```sh
docker start mmt-local-db
```

Если порт `5432` занят, замените в команде Docker левый порт на `5433`, например `127.0.0.1:5433:5432`. После этого откройте `.env` и измените порт в адресе локальной базы на `5433`.

## 3. Подготовьте настройки

В папке проекта скопируйте файл-пример настроек:

```sh
cp .env.example .env
```

В Windows PowerShell используйте:

```powershell
Copy-Item .env.example .env
```

Пример настроен для локальной базы из шага 2. Его не нужно заменять адресом базы рабочего сервиса. Для загрузки скриншотов и схем понадобится отдельный тестовый ключ от владельца проекта; без него остальные страницы всё равно запускаются.

Файл `.env` хранит настройки только на вашем компьютере. Не присылайте его другим людям и не добавляйте его в Git.

## 4. Установите библиотеки и создайте таблицы

Убедитесь, что терминал находится в папке `Minecraft-Material-Tracker`, затем выполните команды по очереди:

```sh
npm ci
npx prisma validate
npm run db:deploy
```

- `npm ci` устанавливает библиотеки, нужные сайту.
- `npx prisma validate` проверяет описание базы.
- `npm run db:deploy` создаёт таблицы в локальной базе.

Если подключиться не удалось, проверьте, что контейнер работает: `docker start mmt-local-db`.

## 5. Создайте первого пользователя локальной копии

Пустому сайту нужен локальный администратор. Введите Minecraft-ник длиной 3–16 символов:

```sh
npm run admin:bootstrap -- MinecraftNick
```

Команда создаёт первого администратора только в локальной базе и показывает временный пароль один раз. Сохраните его, запустите сайт и смените пароль при первом входе.

Если команда пишет, что администратор уже существует, используйте существующий аккаунт локальной копии. После входа можно создавать тестовых пользователей в `/admin`.

## 6. Запустите сайт

```sh
npm run dev
```

Не закрывайте терминал, пока пользуетесь сайтом. Откройте [http://localhost:3000](http://localhost:3000), затем войдите с ником и временным паролем, созданными на предыдущем шаге.

Чтобы выключить сайт, нажмите `Ctrl+C` в терминале. После перезапуска компьютера сначала откройте Docker Desktop и включите базу командой `docker start mmt-local-db`.

## Если не получилось

| Сообщение | Что проверить |
| --- | --- |
| Docker не может подключиться | Откройте Docker Desktop и дождитесь запуска. |
| Порт `5432` уже используется | Запустите базу на порту `5433` и укажите этот порт в локальном `.env`. |
| Prisma не подключается | Включите контейнер `mmt-local-db`; проверьте, что он использует тот же порт, что указан в `.env`. |
| Страница просит сменить пароль | Это ожидаемый первый вход с временным паролем. |
| Не загружается файл | Для загрузки нужен отдельный тестовый ключ; попросите его у владельца MMT. |
| Порт `3000` занят | Запустите сайт командой `npm run dev -- --port 3001` и откройте `http://localhost:3001`. |

Если просите помощи, пришлите только текст ошибки. Не прикладывайте `.env`, пароли или ключи.

