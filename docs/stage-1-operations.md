# Этап I: запуск и безопасная миграция

## Перед развёртыванием

1. Остановить запись в старую версию приложения.
2. Настроить секрет `DATABASE_URL` с PostgreSQL URL (`postgresql://...`) и создать проверенную резервную копию: `npm run db:backup`.
3. Скопировать backup во внешнее защищённое хранилище и проверить восстановление на тестовой БД.
4. Использовать Node.js 20 или 22 и выполнить `npm install`. Скрипт `postinstall` автоматически создаст Prisma Client. Затем выполнить `npx prisma validate` и `npm run db:deploy` сначала на копии PostgreSQL.
5. Если прежняя версия использовала SQLite, сохранить отдельную копию `prisma/dev.db`, а после применения миграций выполнить `npm run db:migrate:sqlite -- /путь/к/dev.db`. Импорт идемпотентен и сохраняет ID, поэтому старые ссылки продолжают работать.
6. Проверить количество и выборку существующих построек. Поле владельца у старых записей намеренно остаётся пустым — администратор сможет назначить владельца после достоверной идентификации.
7. Создать первого администратора: `npm run admin:bootstrap -- MinecraftNick`. Временный пароль выводится один раз и должен быть передан безопасным каналом.
8. Выполнить smoke-тест входа, смены пароля, выхода со всех устройств, создания игрока и постройки.

## Откат

Остановить приложение, восстановить сделанный backup и развернуть предыдущий commit. Не удалять резервную копию до завершения ручной сверки данных.

## Эксплуатация

- Создавать резервные копии по расписанию и регулярно проверять восстановление.
- Не передавать временные пароли в общих чатах.
- После блокировки, сброса пароля и изменения чувствительных данных активные сессии отзываются.
- Логи административных и значимых пользовательских действий хранятся в `AuditLog`.

## Если Prisma Client не найден

В старой версии `package-lock.json` не содержал пакеты Prisma, хотя они были перечислены в `package.json`. Из-за этого установка по lock-файлу оставляла приложение без `@prisma/client`. Устаревший lock-файл удалён: выполните `npm install` в среде с доступом к npm, чтобы npm сформировал новый согласованный lock-файл. После установки `postinstall` автоматически запускает `prisma generate`; отдельно это можно повторить командой `npm run prisma:generate`.
