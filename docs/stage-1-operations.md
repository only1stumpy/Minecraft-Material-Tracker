# Этап I: запуск и безопасная миграция

## Перед развёртыванием

1. Остановить запись в старую версию приложения.
2. Создать проверенную резервную копию: `npm run db:backup`.
3. Скопировать backup во внешнее защищённое хранилище и проверить восстановление на тестовой БД.
4. Выполнить `npm install`, `npx prisma generate` и `npm run db:deploy` сначала на копии БД.
5. Проверить количество и выборку существующих построек. Поле владельца у старых записей намеренно остаётся пустым — администратор сможет назначить владельца после достоверной идентификации.
6. Создать первого администратора: `npm run admin:bootstrap -- MinecraftNick`. Временный пароль выводится один раз и должен быть передан безопасным каналом.
7. Выполнить smoke-тест входа, смены пароля, выхода со всех устройств, создания игрока и постройки.

## Откат

Остановить приложение, восстановить сделанный backup и развернуть предыдущий commit. Не удалять резервную копию до завершения ручной сверки данных.

## Эксплуатация

- Создавать резервные копии по расписанию и регулярно проверять восстановление.
- Не передавать временные пароли в общих чатах.
- После блокировки, сброса пароля и изменения чувствительных данных активные сессии отзываются.
- Логи административных и значимых пользовательских действий хранятся в `AuditLog`.
